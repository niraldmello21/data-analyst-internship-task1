# Data Analyst Internship – Task 1

## Data Cleaning and Preprocessing

### Dataset

Sales Data

### Objective

Clean and prepare the raw sales dataset for analysis.

### Cleaning Performed

* Checked all columns for missing values.
* Found **1 missing value in the Region column** and left it blank because the correct region could not be determined from the available data.
* Checked the dataset for duplicate records and removed duplicates where found.
* Standardized the date format to **dd-mm-yyyy**.
* Standardized column names using underscores.
* Checked and corrected data types for dates, text, and numerical columns.

### Final Columns

* Order_Date
* Region
* Manager
* Sales_Man
* Item
* Units
* Unit_Price
* Sale_Amt

### Tools Used

* Microsoft Excel
* GitHub

### Result

The dataset was cleaned and structured for further data analysis and visualization.
